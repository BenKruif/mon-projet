# Application Web de Diffusion d’Informations pour les Étudiants

## Libellé du Thème

Application web permettant de diffuser des messages et informations à l'endroit des étudiants d'un établissement.

## Problématique

- Les étudiants ne reçoivent pas les annonces d’ordre général venant de l’administration.
- Les étudiants distants (ou ne pouvant venir à PIGIER) n’ont pas accès aux informations affichées par l’administration.
- Les étudiants ne reçoivent pas les informations urgentes concernant la disponibilité d’un enseignement ou un changement de salle à temps.

## Objectif Général

Développer par groupe de quatre étudiants une application web permettant de diffuser des annonces et informations aux étudiants du groupe PIGIER en 10 séances de 2 heures.

## Objectifs Spécifiques

L’application devra être capable de :

- Envoyer les notes individuelles de chaque étudiant.
- Envoyer les emplois du temps.
- Alerter d’un changement de salle.
- Alerter sur la disponibilité d’un enseignement.
- Alerter sur les retards ou incidents de paiement de scolarité.

## Résultats Attendus

- Une application web fonctionnelle.
- Un guide utilisateur pour l’application.
